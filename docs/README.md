# ドキュメント一覧

このフォルダには、設計メモ、要件整理、運用メモをまとめています。

- `design-spec.md`: 設計書の入口
- `design-spec-v0.1.md`: 現在の設計書
- `owner-request.md`: 本人要望のメモ
- `tag-guideline-notes.md`: タグとガイドラインの確定情報
- `assets-workflow.md`: 画像や素材の整理ルール
- `image-placement-guide.md`: 画像をどこに置くかと使い方の案内
- `future-ideas.md`: 将来追加したい機能案
- `update-guide.md`: 半自動更新と Git 運用手順
- `test-visual-review.md`: 残している test 案の比較レビュー
- `site-research-notes.md`: モバイルUI、表示速度、アクセシビリティ、埋め込みの調査メモ
- `homepage-link-info.md`: ホームページに載せるリンク情報

公開サイトの方向性や更新方法を確認するときは、このフォルダ内の文書を参照します。
