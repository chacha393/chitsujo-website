# Future Ideas

このメモは、`CHITSUJO-WEBSITE` の将来追加したい機能や見せ方の案を整理するためのものです。
現時点では「全部を実装する前提」ではなく、本人に見せながら好みや優先順位を確認するための候補集として扱います。

## 前提

- 主ターゲットはスマホユーザー
- 情報量は多すぎない方がよい
- 雰囲気重視のトップページ案を複数比較していく
- 公式サイトっぽさは出したいが、ファンサイトのような押しつけ感は強くしすぎない
- 手作業で更新しやすい構成を優先する

## すぐやりやすい案

### 1. YouTube の最新動画エリア

- トップページに「最新動画」を1本だけ大きく見せる
- その下に「切り抜き / アーカイブ」を1本か2本並べる
- `index_main.html` の日記まわりを土台にすれば実装しやすい
- 最初は手動更新にして、動画URLを差し替える方式が安全

必要なもの

- 埋め込みたい YouTube の動画URL
- 最新動画として見せたい順番
- 切り抜きも載せるかどうか

実装メモ

```html
<iframe
  src="https://www.youtube-nocookie.com/embed/VIDEO_ID"
  title="YouTube video player"
  loading="lazy"
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
  allowfullscreen
></iframe>
```

### 2. Pick Up カード

- `新着動画`
- `配信予定`
- `グッズ`
- `お知らせ`

この中から2〜3個だけを短いカードで見せる

メリット

- 情報を詰め込みすぎず更新感を出せる
- スマホでも見やすい
- 画像がなくてもテキストだけで成立する

### 3. Mobile Shortcuts

- 画面下に `Home / Profile / Gallery / Links` の固定ショートカットを置く
- スマホ向けとしてかなり相性がよい
- hover に頼らず、タップだけで移動できる

注意点

- 画面下を占有しすぎないこと
- ボタン数は4つ程度までに絞ること

### 4. Profile の見せ方強化

- `肩書き`
- `ママ`
- `タグ`
- `好きなもの`

この4つだけを短く見せるプロフィールカードをトップにも置ける

メリット

- `profile.html` へ行かなくても最低限の印象が伝わる
- 本人紹介が薄すぎる状態を防げる

### 5. ギャラリー導線の強化

- トップに `Illustration` セクションを小さく置く
- 最新1枚だけを見せて `もっと見る` で `gallery.html` へ飛ばす
- 作品が増えてもトップの情報量を増やしすぎずに済む

### 8. Guideline 専用ページ

- いまはトップやプロフィールに要点だけ載せる

メリット

- 常設でもうるさくなりにくい
- 販売中だけ出す運用にしやすい

### 10. 季節や記念日に合わせた Hero 切り替え

## 長期で考えたい案

### 11. YouTube の自動取得

- 最新動画を自動で表示
- ライブ配信中なら `LIVE` 表示

注意点

- 外部APIや外部サービスが必要になる可能性が高い
- 実装難易度が上がる
- まずは手動更新の方が安全

### 12. X や YouTube の埋め込み連動

- 固定ポスト
- 最新投稿
- チャンネル紹介

ただし、埋め込みを増やしすぎるとスマホで重くなるので注意

### 13. `index_main` を軸に改造していく運用

- `index_main.html` を作業用として改造する
- `test4-save.txt` を保存版として残す
- 必要なら `index_main` から分岐して別案を作る

使い方

- 本人に見せて反応を集める
- 好きな要素を抽出する
- 最終的に1ページへ統合する
